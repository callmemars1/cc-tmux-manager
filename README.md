# cc — менеджер tmux-сессий с Claude Code

Единица работы — **задача**, а не директория. Одна задача = одна tmux-сессия с
запущенным в ней Claude Code. Сессия называется по смыслу задачи, поэтому
`cc ls` читается как список того, чем сейчас занят каждый агент.

## Требования

- `bash`
- `tmux`
- `claude` в `PATH` (или путь в `CLAUDE_BIN`)

## Установка

```bash
git clone git@github.com:callmemars1/cc-tmux-manager.git
install -m 755 cc-tmux-manager/cc ~/.local/bin/cc
```

Либо симлинком, чтобы обновляться через `git pull`:

```bash
ln -s "$PWD/cc-tmux-manager/cc" ~/.local/bin/cc
```

## Команды

| Команда | Что делает |
| --- | --- |
| `cc "задача словами"` | новая сессия с временным именем `t-HHMMSS`; Claude сам переименует её по смыслу задачи |
| `cc <slug> [задача...]` | явное имя сессии (аргумент без пробелов — это слаг, а не задача) |
| `cc -C <dir> <slug> [...]` | то же, но в другой рабочей директории |
| `cc ls` (или без аргументов) | сессии: подключена ли, чем занята, последняя строка вывода |
| `cc a <slug>` | подключиться, отобрав сессию у зависшего клиента |
| `cc peek <slug>` | хвост сессии, не подключаясь |
| `cc mv <old> <new>` | переименовать сессию (лог переезжает вместе с ней) |
| `cc log <slug>` | писать вывод сессии в `~/.cc-logs/<slug>.log` |
| `cc kill <slug>` / `cc killall` | убить сессию / весь tmux-сервер |

Если сессия с таким именем уже есть, `cc <slug> задача` не создаёт новую, а
досылает текст в существующую.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `CC_DIR` | текущая директория | рабочая директория новых сессий |
| `CC_AUTOLOG` | выключено | `1` — включать `pipe-pane` сразу при создании сессии |
| `CC_AUTONAME` | `1` | `0` — не просить Claude переименовывать временную сессию |
| `CLAUDE_BIN` | `claude` | чем запускать Claude Code |
| `CLAUDE_FLAGS` | пусто | доп. флаги к запуску |

## Как работает автопереименование

Сессия из `cc "задача словами"` стартует под именем `t-HHMMSS`. Claude получает
через `--append-system-prompt` инструкцию вывести из первого запроса короткий
kebab-case слаг и вызвать `cc mv t-HHMMSS <slug>`. Отключается через
`CC_AUTONAME=0`.

`cc ls` показывает задачу из `pane_title`: Claude Code кладёт туда текущее
занятие, обычный шелл — `user@host:cwd` (в этом случае выводится только `cwd`).
